# ZSH Custom

- Note that OMZ sources files in alphabetical order. So I use numbers to drive the order.
- Define local/private paths in paths.local.zsh or any .local.zsh file named with an index similar to the others in this directory. Any unused number is available for local files.
- No credentials here. They live in ~/.config/env.d, loaded per-directory by direnv. See Credentials in the root README.
- 12-flags.local.zsh installs the direnv hook.
